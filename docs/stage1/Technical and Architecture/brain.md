# Brain

The brain is the decision-making and learning component of the system.

Its responsibility is to:

* receive observations
* estimate action values
* choose actions
* update internal learning state
* shape behavior through both external and internal rewards

The brain operates independently from the environment internals and interacts with the system only through observations and rewards provided by the environment interface.

This separation keeps the learning system modular and allows the surrounding architecture to evolve without tightly coupling the “brain” to the world implementation.

---

# Structure

The current brain architecture is divided into several independent components:

```txt id="6d6t1e"
Brain
├── Q-Table System
├── Policy System
└── Reward Shaping System
```

Each subsystem has its own responsibility and operates independently from the others through controlled interfaces.

This separation makes it possible to later replace or extend individual systems without rewriting the entire learning pipeline.

---

# Q-Table System

The Q-table subsystem is responsible for:

* storing value estimates
* updating learned values
* estimating future reward potential

The system stores estimated values for taking action (a) in state (s):

Q(s,a)

Conceptually, the structure can be viewed as:

```txt id="1f11e2"
States × Actions → Estimated Values
```

Each value represents:

> how useful a specific action appears to be in a particular state based on previous experience.

At the beginning of training, the table contains little or no useful information.
Over time, interaction with the environment gradually reshapes these estimates.

---

# Learning Update

The Q-table is updated using the Bellman equation:

Q(s,a) \leftarrow Q(s,a)+\alpha(r+\gamma \max Q(s',a')-Q(s,a))

where:

* (r) is the received reward
* (\alpha) is the learning rate
* (\gamma) controls future reward importance
* (\max Q(s',a')) estimates the best possible future action

The update process continuously adjusts estimates toward more successful behavior patterns.

---

# TD Error

Learning updates are driven by Temporal Difference (TD) error:

\delta=r+\gamma \max Q(s',a')-Q(s,a)

TD error represents:

> the difference between expected outcome and observed outcome.

This signal acts as the correction mechanism that gradually improves future estimates.

The system also logs TD error values during training to analyze:

* learning stability
* reward dynamics
* policy behavior
* exploration patterns

---

# Policy System

The policy subsystem controls how actions are selected from learned Q-values.

The current policy system combines:

* argmax
* ε-greedy exploration
* ε decay

---

## Argmax

Argmax selects the action with the highest estimated value.

Conceptually:

```txt id="8dzd93"
choose action with highest Q(s,a)
```

This creates exploitative behavior focused on maximizing expected reward.

---

## ε-greedy Exploration

Pure exploitation creates a major problem:

* the agent may stop exploring too early
* early mistakes may become permanent
* the system can converge to weak local strategies

To avoid this, the policy introduces ε-greedy exploration.

With probability:

* (1 - \varepsilon) → choose best known action
* (\varepsilon) → choose random action

This allows the system to continue discovering new states and behaviors during training.

---

## ε Decay

Exploration strength decreases over time through ε decay.

Early training prioritizes exploration because the system initially has very little information about the environment.

As training progresses:

* random exploration becomes weaker
* learned strategies become more dominant
* behavior gradually stabilizes

This creates a transition from:

* exploration
  toward:
* exploitation

---

# Reward Shaping System

The brain also contains a separate reward shaping subsystem.

Its purpose is to generate internal rewards independently from the environment itself.

This subsystem currently includes:

* curiosity-driven exploration rewards

The reward shaping layer acts as an additional behavioral pressure system on top of environmental rewards.

---

# External vs Internal Rewards

The architecture separates rewards into two categories.

## External rewards

Generated directly by the environment:

* positive objects
* danger objects
* environmental interactions

These rewards describe:

> how the world reacts to the agent.

---

## Internal rewards

Generated by the brain through reward shaping systems.

These rewards describe:

> how the learning system internally encourages behavior.

Current internal rewards focus on exploration pressure through curiosity.

This separation keeps learning logic independent from world logic and prevents the environment from becoming overloaded with behavior-specific mechanisms.

---

# Curiosity System

The current curiosity mechanism rewards exploration of less-visited states.

The curiosity reward follows:

r_{curiosity}=\frac{\beta}{\sqrt{N}}

where:

* (N) is the number of visits to a state
* (\beta) controls curiosity strength

The effect of this mechanism is that:

* unexplored states become more attractive
* repeated states gradually lose exploratory value
* the agent is pushed toward broader exploration

This helps reduce passive behavior and weak local strategies.

---

# Curiosity Decay

Curiosity strength also decreases during training.

At early stages:

* exploration pressure is high
* discovering new states is strongly encouraged

Later:

* curiosity weakens
* learned strategies stabilize
* excessive wandering decreases

This allows the system to gradually shift from exploration-heavy behavior toward more consistent policy execution.

---

# Observation-Based Interaction

The brain only receives observations generated by the environment.

Interaction flow:

```txt id="oqvrwb"
Environment → Observation → Brain → Action
```

The brain does not directly access:

* full map data
* environment internals
* object placement systems

This abstraction reduces coupling and improves scalability of the overall architecture.

---

# Current Capabilities

At Stage 1, the brain is capable of:

* learning simple reward associations
* exploration through ε-greedy behavior
* curiosity-driven exploration
* adapting movement strategies
* balancing exploration and exploitation
* stabilizing behavior over time

The system already demonstrates several emergent patterns:

* aggressive early exploration
* reward-seeking behavior
* reduced exploration after learning
* avoidance of negative areas

---

# Current Limitations

The current brain architecture still lacks:

* memory
+ Possibilities to drink vodka
* planning
* representation learning
* long-term reasoning
* communication

The learning process also remains strongly dependent on:

* reward design
* environment simplicity
* handcrafted state representations

These limitations are expected at Stage 1 and will be addressed in future stages through more advanced learning systems.
